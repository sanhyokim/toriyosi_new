# 本番サーバー（さくらのレンタルサーバ）の操作手順

オーナー向けに、画面に出る名前を使ってクリック単位で書いています。AI エージェントがオーナーに作業を頼むときも、この粒度で説明してください。
（2026-10-11 の初回公開で実際に使った手順をもとにしています。アカウント名・パスワード・データベース名はここには書きません。）

ログイン先は **さくらのレンタルサーバのコントロールパネル**（https://secure.sakura.ad.jp/rs/cp/ ）です。WordPress の管理画面（/wp-admin）はもう使いません。

| ドメイン | 公開フォルダ |
|---|---|
| toriyoshi-love.sakura.ne.jp（初期ドメイン） | `~/www/` |
| **toriyoshi.love（本番サイト）** | **`~/www/wp`** |

`~` は「自分のホームフォルダ」の意味です。作業する場所は **`www` フォルダの中の `wp` フォルダ** です。

## 触ってはいけないもの

`wp` フォルダの中の次のものは、**削除・移動・上書きしない**でください。

- `wp-content`（旧サイトの写真など）
- `_wp_old`（退避した旧 WordPress。元に戻すときに使う）
- `google` で始まる `.html` ファイル（Google Search Console の所有確認用）
- `.well-known` フォルダ（あれば）

また、同じサーバーにある **radiant-me.love（別のサイト）** のフォルダとデータベースには触りません。

## 更新のしかた（いつもの作業）

AI エージェント（または開発者）から `toriyoshi-dist.zip` を受け取ったら、次の順に操作します。

1. コントロールパネル左メニューの **「Webサイト/データ」** をクリック
2. 開いたメニューから **「ファイルマネージャー」** をクリック（別タブで開くことがあります）
3. 左側のフォルダ一覧で **`www`** → **`wp`** の順にクリックして開く
4. 画面右上あたりの表示設定で **「隠しファイルを表示」** をオンにする（`.htaccess` が見えるようになります）
5. **「アップロード」** を押し、パソコンの `toriyoshi-dist.zip` を選ぶ
6. アップロードされた `toriyoshi-dist.zip` を右クリック → **「リモートで解凍」**
   - 「上書きしますか」と聞かれたら **上書き** を選びます
   - もし `toriyoshi-dist` という名前のフォルダが 1 段できて、その中にファイルが入っていたら、中身を全部選んで 1 つ上（`wp`）に移動してください
7. `toriyoshi-dist.zip` を右クリック → **「削除」**
8. スマホとパソコンの **シークレットウィンドウ** で https://toriyoshi.love/ と変更したページを開いて確認

> 「リモートで解凍」が使えないときは、パソコンで zip を展開し、中身をすべて選んで「アップロード」の画面にドラッグしてください（フォルダごとアップロードできます）。

ページを削除した更新（お知らせを消した、など）のときは、上書きしても古いページのフォルダが残ります。AI エージェントが「`news/○○` フォルダを削除してください」と伝えるので、そのフォルダを右クリック →「削除」してください。

### 解凍後の `wp` フォルダの中身（正常な状態）


## 元に戻したいとき（WordPress に戻す）

1. ファイルマネージャーで `www` → `wp` を開く
2. 新サイトのファイル（上の一覧のうち `wp-content`、`_wp_old`、`google○○.html` **以外**のもの全部）を選んで右クリック →「削除」
3. `_wp_old` を開き、中身を全部選んで右クリック →「指定の場所に移動」→ 移動先に `wp` を指定
4. https://toriyoshi.love/ を開くと WordPress が表示されます

それでも戻らないときは、公開前に取ったデータベースのエクスポート（`.sql`、オーナーの手元）から、コントロールパネル「Webサイト/データ」→「データベース」→ 管理ツール（phpMyAdmin）の「インポート」で復元します。

## 初回公開のときにやったこと（記録）

2026-10-11 に、次の順で WordPress から新サイトへ切り替えました。

1. データベースのバックアップ: 「Webサイト/データ」→「データベース」→ 右上「全体設定 ▼」→「管理ツールログイン」→ phpMyAdmin で WordPress のデータベースを選び「エクスポート」→「実行」
   - 同じ画面にある radiant-me.love 用のデータベースは触らない
2. ファイルのバックアップ: `wp` フォルダを「リモートで圧縮」しようとしたが、大きすぎて「処理が失敗しました」になった。失敗するとランダムな名前の作りかけファイルが `www` に残るので削除した。この手順は何も消さない（移動だけ）ため、ファイルのバックアップは省略した
3. `wp` の中に `_wp_old` フォルダを作り、WordPress 本体（`wp-admin`、`wp-includes`、`index.php`、`wp-` で始まる `.php` 全部、`xmlrpc.php`、`license.txt`、`readme.html`、`wp-cli.local.yml`、`.htaccess`）を移動。`wp-content` と `google○○.html` は動かさない
4. `toriyoshi-dist.zip` をアップロードして「リモートで解凍」
5. 全ページの表示を確認
6. Google Search Console に URL プレフィックス `https://toriyoshi.love/` で登録（HTML ファイル `google○○.html` を `wp` に置いて所有確認）し、`https://toriyoshi.love/sitemap.xml` を送信

### FTP を使う場合（ファイルマネージャーがうまく動かないとき）

FileZilla（無料）などで接続します。ホストは初期ドメイン、ユーザー名とパスワードはコントロールパネルのサーバー情報のもの。暗号化は「明示的な FTP over TLS が必要」、文字コードは **UTF-8 を強制**（お知らせに日本語名のフォルダがあるため）、メニュー「サーバー」→「隠しファイルを強制表示」をオンにします。
